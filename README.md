### AtoZCaterers – Catering & Event Management Website

**AtoZCaterers** is a Django-based catering and event management website developed to provide customers with an easy way to explore catering services, browse food options, and make catering inquiries or bookings online. The project focuses on creating a simple, responsive, and user-friendly platform that can be developed and deployed within a short time.

**Key Features:**

* User-friendly home page showcasing catering services
* Food/menu categories with detailed information
* Catering packages and service details
* Event-based catering options such as weddings, parties, and corporate events
* Customer inquiry/booking form
* Contact and service information
* Django-based backend for managing website data
* Responsive design for desktop and mobile devices
* Admin panel for managing menus, services, and customer inquiries

**Technologies Used:**

* Python
* Django
* HTML
* CSS
* Bootstrap
* JavaScript
* SQLite/MySQL
* Django ORM

**Project Objective:**
To build a complete catering website quickly using Django, providing a professional online presence for catering businesses while allowing customers to easily discover services and submit booking or inquiry requests.
